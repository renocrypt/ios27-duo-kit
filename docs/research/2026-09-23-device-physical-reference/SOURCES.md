# Reference asset manifest — iPhone Duo physical reference

Checked: September 23, 2026. The files listed here stay outside the project,
in `/tmp/duo/device-research/references/`: disposable working references for
measuring and describing the real device, and this manifest is how to get them
again. Per project rules, none of Apple's images, PDFs, or 3D models are copied
into the `duo/` project folder — only descriptions, numbers, and citations
derived from them are.

## Derived/working files (not primary sources, kept for traceability)

- `overview.built.css` (in the parent working folder, not copied here) — Apple's production CSS for the iPhone Duo product page; contains the two colorway swatch hex values quoted in the JSON spec (`--finish-iphoneduo-night-sky:#394452`, `--finish-iphoneduo-star-white:#f7f6f5`).
- Blender inspection scripts and their text output (in the parent working folder) — record of the geometry measurements taken from the USDZ, kept for reproducibility.
